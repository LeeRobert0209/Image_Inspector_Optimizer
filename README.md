## 🚀 核心功能详解

### 1. 📊 图片体检中心 (Inspector)
> *"不仅看尺寸，更看质量"*

*   **双视图报表**: 自动生成 Excel，包含 `概览 (Overview)` 和 `详细数据 (Details)` 两个工作表。
*   **印刷级字段**:
    *   **基础**: 文件名、完整路径、色彩模式 (RGB/CMYK)、格式。
    *   **进阶**: 
        *   **尺寸**: 像素宽高 (px)
        *   **分辨率**: 真实 DPI 读取 (默认为 72)
        *   **物理尺寸**: 自动换算打印尺寸 (Based on DPI, unit: cm)
        *   **总像素**: 百万像素值 (MP)，快速判断图片精度。
*   **智能数据源**: 支持拖入“文件夹”或包含路径的“Excel清单”进行分析。

### 2. 🏭 标准化处理车间 (Optimizer)
> *"三级分层逻辑 + LANCZOS 影院级重采样"*

系统根据图片特征，自动将其分流至三条处理管线，确保在压缩体积的同时保留最佳画质：

*   **🔴 R1 管线 (超大图)**: 针对海报/单反原图。
    *   触发: 宽 > 1920px 且 体积 > 0.5MB
    *   动作: **LANCZOS 重采样**至 1920px，质量 Q80。
*   **🔵 R2 管线 (常规图)**: 针对电商详情页/文章配图。
    *   触发: 宽 800-1200px 且 体积 > 0.3MB
    *   动作: **LANCZOS 重采样**至 800px，质量 Q70。
*   **⚪ R3 管线 (小图)**: 针对缩略图/图标。
    *   触发: 宽 < 400px 且 体积 > 30KB
    *   动作: 智能降质循环，直到体积 < 30KB (保持尺寸不变)。
*   **🛡️ 物理隔离**: 所有处理后的图片均存放于 `_Optimized` 子文件夹，**绝不覆盖原图**。

## 📦 如何使用

### 方式 A：全能模式 (推荐)
1.  双击 **`启动全能工具箱.bat`**。
2.  在左侧导航栏切换 **“图片体检”** 或 **“标准化车间”**。
3.  **体检**: 拖入文件夹，等待 Excel 报告生成。
4.  **处理**: 设定好参数（或使用默认推荐值），选择文件夹，一键清洗。

### 方式 B：独立模式
*   若只需分析：运行 `启动分析工具.bat`。
*   若只需处理：运行 `启动标准化处理.bat`。
